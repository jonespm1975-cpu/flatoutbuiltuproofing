2. Upload the THREE files in this ZIP into the ROOT of the same repository.
3. If GitHub asks to replace index.html, do so ONLY after making the backup.
4. Commit changes, wait for GitHub Pages to finish, then open https://flatoutbuiltuproofing.co.uk
5. Test Login, the free lesson, the new free beginner page, manager.html and other existing pages.
6. If anything breaks, restore the backed-up index.html in GitHub.
